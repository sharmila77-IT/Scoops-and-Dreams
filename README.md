# Scoops & Dreams 🍦

A modern and visually appealing ice cream ecommerce frontend website built using HTML, CSS, and JavaScript.

##  Features
- User Login System
- Product Search & Filtering
- Interactive Payment UI
- Responsive Design
- LocalStorage Integration
- Modern Glassmorphism UI
- Product Details Page
- Order Confirmation Flow

##  Technologies Used
- HTML5
- CSS3
- JavaScript
